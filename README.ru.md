# WinCreative

[English](README.md) | **Русский**

WinCreative — бесплатное приложение для рисования с открытым исходным кодом для Windows, сделанное в духе Procreate и рассчитанное на графические планшеты и сенсорные экраны.
Это независимый проект, не связанный с Savage Interactive и не одобренный ею (см. [Товарные знаки](#товарные-знаки-и-брендинг)).

Electron + TypeScript + electron-vite, графический движок на WebGL2.

![Главное окно WinCreative](docs/screenshots/main.png)

## Возможности

* **Поддержка планшетов**: нажим, наклон, вращение пера, ластик на конце пера, кнопки пера (переназначаемые), курсор при наведении, редактируемая кривая нажима, диагностика планшета. Работает через Windows Ink / Pointer Events (Wacom, Huion, XP-Pen, Surface и др.). Жесты: масштаб, поворот и сдвиг, отмена и повтор несколькими пальцами.
* **106 мягких кистей со сглаживанием** в 19 наборах и **Студия кистей** для создания и настройки собственных. Импорт `.brush`, `.brushset` и `.abr` работает по мере возможности.
* **Слои**: 26 режимов наложения, маски, группы, обтравочные маски, блокировка прозрачности, опорные слои, объединение и сведение.
* **Коррекции**: оттенок/насыщенность/яркость, цветовой баланс, кривые, карта градиента, размытия, Bloom, Glitch, полутона и другие; применяются к слою или наносятся пером. Есть **Пластика (Liquify)** и Клон.
* **Выделение и трансформация**: свободное, фигурное и цветовое выделение, свободная трансформация, деформация и искажение.
* **Направляющие, симметрия и QuickShape**: сетка, изометрия, перспектива и симметрия с привязкой; нарисуйте и задержите перо, чтобы выровнять линию, круг или многоугольник; стабилизация StreamLine.
* **Текст** с импортом шрифтов.
* **Помощник анимации** с калькой.
* **Таймлапс**: записывается каждый мазок; просмотр, редактор таймлапса (скрытие отменённых действий, паузы, гибкая скорость и скорость по сегментам, подгонка под заданную длительность, финал) и экспорт в **MP4** (и в изображение).
* **Импорт и экспорт PSD** (слои, маски, режимы наложения, текстовые и корректирующие слои при импорте), экспорт в PNG/JPEG/WebP/TIFF/PDF, собственный формат `.bwk`.
* **Интерфейс на английском и русском**, переключается на лету.
* **Интерактивное обучение**: 13 коротких уроков на тренировочном холсте и справочник по жестам и перу.

## Установка

1. Скачайте последний установщик (`WinCreative-Setup-<версия>.exe`) или портативную версию на странице
   [Releases](https://github.com/lifechangee/WinCreative/releases).
2. Нужна **Windows 10 или 11, x64**.
3. Установщик **не имеет цифровой подписи**, поэтому Windows SmartScreen покажет предупреждение («Windows защитила ваш компьютер»). Нажмите «Подробнее», затем «Выполнить в любом случае». Либо соберите приложение из исходников (ниже).

### Советы для планшетов

* Установите драйвер планшета и, для Wacom/Huion/XP-Pen, включите **Windows Ink** в настройках драйвера (нужно для передачи нажима в Electron-приложения).
* Отключите **кольцо долгого нажатия** Windows Ink: *Параметры > Bluetooth и устройства > Перо и Windows Ink > Дополнительные параметры пера*, снимите флажок «Нажать и удерживать для щелчка правой кнопкой». Серое кольцо при удержании пера мешает длинным мазкам и фиксации фигур. Опцию долгого нажатия в драйвере тоже лучше отключить.
* Нажим ощущается неверно? Откройте *Действия > Настройки > Нажим и сглаживание*, измените кривую и запустите «Диагностику планшета».

## Сборка из исходников

Требуется **Node.js 20 или новее** на Windows (упакованное приложение и встроенный FFmpeg рассчитаны на Windows x64).

```
npm install
npm run dev        # запуск в режиме разработки
npm run build      # проверка типов и сборка в out/
npm run dist       # сборка и упаковка установщиков в release/
npm test           # модульные тесты (vitest)
npm run selftest   # самотесты внутри приложения (запускает Electron)
npm run i18n:check # поиск неперевёденных строк интерфейса
```

Структура проекта и заметки по устройству: [ARCHITECTURE.md](ARCHITECTURE.md). Список функций: [FEATURES.md](FEATURES.md).
Правила локализации: [docs/I18N.md](docs/I18N.md). Скрипты UI-тестов на Playwright (в том числе делающий скриншоты выше) лежат в `scripts/qa/`.

## Состояние и известные ограничения

Это **ранняя версия (0.2.0)**. Она тестировалась в основном на синтетическом вводе и нескольких планшетах, поэтому с некоторыми устройствами и драйверами возможны шероховатости.

* Импорт `.procreate`, `.brush`, `.brushset` и `.abr` работает по мере возможности (форматы не документированы).
* Нет CMYK; управление цветом ограничено sRGB-профилями со встраиванием ICC.
* Только Windows.
* О проблемах сообщайте (с указанием модели планшета и драйвера) в [Issues](https://github.com/lifechangee/WinCreative/issues).
